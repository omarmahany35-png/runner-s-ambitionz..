# Runner's Ambitionz

## Game Description

Runner's Ambitionz is a 2D Adventure RPG game where the player must survive dangerous paths filled with enemies while collecting as many coins as possible. The player can fight enemies using a sword, avoid getting overwhelmed, and continue progressing through different levels to safely reach the final destination.

The game features enemy combat, health regeneration over time, coin collection, and level transitions that create a simple but engaging RPG adventure experience.

## How to Play

Your goal is to survive the journey, defeat or avoid enemies, collect coins, and safely reach the end of the path without dying.

Stay on the main road to avoid getting lost and manage your health carefully while fighting enemies.



## Controls

* Move Up → Up Arrow
* Move Down → Down Arrow
* Move Left → Left Arrow
* Move Right → Right Arrow
* Attack → Left Mouse Click or E


## Features

* Top-down Adventure RPG gameplay
* Sword combat system
* Enemy AI and attack system
* Coin collection system
* Health regeneration over time
* Multiple levels with scene transitions
* Animated player movement and attacks
* Collision and combat mechanics



## Built With

* Engine: Godot 4.6
* Programming Language: GDScript
* Art Assets: Downloaded assets with custom map design

## Inspiration

This project was inspired by classic RPG adventure games where players explore dangerous areas, fight enemies, and progress through different maps while collecting rewards.

The main goal of the project was to practice game development fundamentals in Godot, including combat systems, enemy interactions, level transitions, and player animation systems.
